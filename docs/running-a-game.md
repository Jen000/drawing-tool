# Running a game

For hosts. No technical knowledge needed — if you can use a website, you can run
this. If you want to set up your own copy instead, see
[Setting up your own](setup.md).

---

## What you need

- A link to a copy of the game, e.g. `https://someone.github.io/drawing-tool/`
- A laptop, ideally plugged into a screen or projector
- Players with phones, on any network — they do not need to be on your wifi

---

> **Coming back?** Open the address and press **Sign in**, top right. If you
> have signed in on that browser before, there is a **Go to my boards** button
> waiting instead — no password to retype. Your boards live with your account,
> so they are there from any laptop. There is also a **Help** button on the
> landing page, the board list and the board itself.

## Before the night

### 1. Make yourself a host account

Open the link and choose **Running the game? → Sign in as host**. Pick *Create
an account*, and use any email and a password of at least six characters.

This account is yours. Nobody playing ever sees it, and it is not shared with
other hosts using the same copy. It exists so your boards follow you to whatever
laptop you present from.

### 2. Make a board

A **board** is one event. Give it a name you will recognise — *Friday
Presentation Night*, *Team offsite* — and create it.

You will land on the board with a **six-character code** like `4FDY8R` and a QR
code. That is what the room uses to join. Bookmark this page.

You can have as many boards as you like. **Switch board** at the top right takes
you back to the list, which shows each board's code next to its name.

**Copy host link** on the board copies the address of that exact board, if you
want to mail it to yourself or park it in your notes.

---

## On the night

### 3. Put the board up

Two ways, depending on your setup:

- **One screen.** Press **Present to the room**. Your controls disappear and the
  screen fills with the topic, timer, join code and drawings. Press `Esc`, or
  the faint button in the corner, to get your controls back.
- **Two screens.** Press **Second screen** — a new window opens with the same
  view. Drag it to the projector and leave your controls on the laptop.

> **Why this matters:** without it, the room sees your topic box, your buttons
> and your email address. Present mode keeps all of that to yourself.

### 4. Get everyone in

The screen shows a QR code, the web address, and the six-character code. People
can either scan, or go to the address and type the code. Both work.

Nobody signs in. Nobody installs anything. They land straight on a blank canvas.

### 5. Set a topic

Type it in the **Topic** box and press **Update topic** or Enter. It appears on
everyone's phone within a few seconds.

Change it as often as you like — the box will not fight you while you are
typing, and a change mid-round does not wipe anyone's drawing.

### 6. Run the timer

Set the minutes and press **Start timer**. Everyone sees the same countdown, to
the second.

- **Pause** freezes it — for a question, a latecomer, a laugh that goes on too
  long. Everyone's timer freezes with it.
- **Resume** picks up exactly where it stopped.
- **Clear** removes the timer entirely.
- **Restart timer** starts fresh from the minutes shown.

When the timer runs out, voting opens on its own.

> **One drawing each per round.** Everyone gets a single entry, so nobody can
> flood the board and the vote stays fair. A new round gives everyone a fresh
> go.

### 7. Vote

**Open voting** puts everyone's drawings on their phones. One vote each, and
they cannot change it once cast. The big screen shows the drawings with live
vote counts.

### 8. Results

**Show results** ranks them, crowns the winner and shows the counts. Everyone
sees it on their phone and on the big screen at the same time — so you can
either look down or all look up together.

### 9. Go again

**New round** clears the board and puts everyone back on a blank canvas, ready
for the next topic.

## Handy things

**Hide drawings** blurs the board so people cannot copy each other while
drawing, or so you can do a dramatic reveal. It hides on every screen at once,
including the projector.

**Download drawings** saves the whole round as a single image with everyone's
name under their picture. Players can save their own with **Save my drawing**
after they submit.

**Close session** shuts the board immediately — nobody can add anything until
you reopen it.

---

## Good to know

**Drawings do not survive the next round.** Starting a new round deletes them.
If a drawing is worth keeping, download it before you move on.

**The board closes itself.** About half an hour after you close the page, the
code stops working. That is deliberate — it means an old code from last month
cannot be used to draw on your board today. Opening the board again reopens it.

**Anyone with the code can join.** Treat it like the door to the room: hand it
to the people you want playing.

---

## If something goes wrong

**Someone cannot join.** Check the board is still open — if you have had the
page closed a while, reload it. Have them type the code instead of scanning; the
codes deliberately avoid characters that get misread, so there is no `O`, `0`,
`I`, `1` or `L` in them.

**Someone's drawing looks squashed.** It should not — tell me if it happens, and
which phone.

**The room can see your controls.** You are not in Present mode. Press **Present
to the room**.

**Nothing is updating.** Everything refreshes every few seconds, so give it a
moment. If it is still stuck, reload — nothing is lost by reloading.
